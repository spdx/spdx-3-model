# serviceHostingCountries

## Summary

Specifies a country code where a software service is hosted.

## Description

This property should specify all countries and territories where a service is located.
This includes indirect locations (e.g. where the data may be hosted).
The string must be in the [ISO 3166-1 alpha-3](https://www.iso.org/obp/ui/#iso:std:iso:3166:-3:ed-2:v1:en) format.  
See the [ISO 3166-1 alpha-3 Wikipedia page](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-3) for more information.
