# serviceHostingCountries

## Summary

Specifies a country code where a software service is hosted.

## Description

This property should specify all countries where a service is located.  This includes indirect locations (e.g. where the data may be hosted).
The string must be in the [ISO 3166-1 alpha-3](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-3) format.
