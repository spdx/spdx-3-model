# DistributionMethodType

## Summary

The DistributionMethodType defines a list of known distribution methods as central reference.

## Description

The field can be used to document the way how an element is distributed in the supply chain.

## Metadata

- name: DistributionMethodType

## Entries

- hosted: Application is not shipped but hosted.
- distributed: Application is shipped to another legal entity.
