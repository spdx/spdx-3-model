# docUrl

## Summary

The primary (URI) serving to publish documentation page for a Project.

## Description

The docUrl provides the definitive entry point for accessing project documentation, technical specifications, and user guides. As a DataProperty with Range xsd:anyURI, it captures the standardized web address that enables traceability between the project model and its external documentation repository.

## Metadata

- name: docUrl
- Nature: DataProperty
- Range: xsd:anyURI
