# assessmentContext

## Summary

Identifies the Project that provides context for an assessment.

## Description

The assessmentContext property identifies the Project within which an assessment is performed or interpreted. It can be used when the scope or result of the assessment depends on project-specific information.

## Metadata

- name: assessmentContext
- Nature: ObjectProperty
- Range: Project
