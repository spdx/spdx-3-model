# participationAgreement

## Summary

A participationAgreement defines the participation parameters to be adhered to by particiapnts.

## Description

participationAgreement represents the formal Specification instances that can define the framework for community involvement in an OpenSourceProject. These specifications may include contributor license agreements (CLAs), Code of Conduct or copyright assignments that dictate how stakeholders may interact with the project.
