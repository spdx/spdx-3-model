# mediaChannel

## Summary

MediaChannel represent: social media links, mailing lists, or other communication channels for the project.

## Description

MediaChannel provides an entry point for project communication and community interaction.  It captures the standardized addresses for social media platforms, mailing lists, discussion forums, and other collaboration or communication channels that facilitate stakeholder engagement.
