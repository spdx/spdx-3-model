# cryptographicAlgorithmExpression

## Summary

A string in the SPDX Cryptographic Algorithm Expression format.

## Description

A cryptographicAlgorithmExpression enables the representation, in a single string, of a
combination of one or more cryptographic algorithms.

The syntax for a SPDX Cryptographic Algorithm Expression string is set forth in the corresponding
Annex [Cryptographic Algorithm Expression](https://github.com/spdx/cryptographic-algorithm-list/tree/main/docs/SPDXCryptographicAlgorithmExpressions.md).
