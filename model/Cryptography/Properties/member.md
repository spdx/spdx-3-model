# member

## Summary

A `CryptographicAlgorithm` instance participating in an algorithm set.

## Description

A member is a `CryptographicAlgorithm` participating in a conjunctive set (`ConjunctiveCryptographicSet`) or a disjunctive set (`DisjunctiveCryptographicSet`) algorithm set.

- name: member
- Nature: ObjectProperty
- Range: CryptographicAlgorithm
