# annotationTime

## Summary

The timestamp at which the certificate state was recorded or observed.

## Description

This property specifies the date and time when the certificate state was recorded or observed. It provides temporal context for the CertificateAnnotationState, allowing users to understand when a particular certificate lifecycle state was noted.

- name: annotationTime
- Nature: DataProperty
- Range: /Core/DateTime
