# sourceElement

## Summary

A reference to the original Element that was used to create or is associated with this CryptographyArtifact.

## Description

The sourceElement property establishes a relationship between a CryptographyArtifact and the original Element it was derived from or is associated with. This property is essential for tracing the lineage of cryptographic materials back to their source data.

- name: sourceElement
- Nature: ObjectProperty
