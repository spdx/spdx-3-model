# serializedArtifact 

## Summary

serializedArtifact is the serialized CryptographyArtifact. This to put the PEM or DER serialized key or certificate.

## Description

serializedArtifact represents the serialized form of a CryptographyArtifact. It is used to store the PEM or DER-encoded representation of a key or certificate.
