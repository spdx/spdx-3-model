# ContactType

## Summary

An enumeration of contact types.

## Description

This enumeration defines common contact types.

## Metadata

- name: ContactType

## Entries

- compliance: A contact point for compliance matters (i.e. export control, licensing).
- other: A generic contact point to be used when the contact type does not match any of the other options.
- securityVulnerability: A contact for reporting security vulnerabilities.
- support: A contact point for support.
