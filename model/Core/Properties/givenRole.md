# givenRole

## Summary

givenRole is a property that specifies the role being assigned in a RoleRelationship. It links the relationship to an instance of the Role class, defining the function, responsibility, or position that the source element confers upon the target element.

## Description

givenRole specific the role that is being assigned or defined by the relationship. This role represents the function, responsibility, or position that the source element (e.g., an organization, tool, or component) confers upon the target element (e.g., a person, team, or system).

- Nature: ObjectProperty
- Range: Role
