# observedCategory

## Summary

IRI of the term that is the result of a CategoryObservation.

## Description

The `observedCategory` property gives the result of a `CategoryObservation`
as the IRI of a term from a code list, such as an energy efficiency class
or a test verdict.

- name: observedCategory
- Nature: DataProperty
- Range: xsd:anyURI
