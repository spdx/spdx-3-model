# unitQUDT

## Summary

A QUDT (Quantity, Unit, Dimension and Type) unit applied to measurement
criteria based on product type, region, and use.

## Description

QUDT (Quantity, Unit, Dimension and Type) specifies a standardized framework
for describing measurable quantities, units of measure, numerical values,
and their underlying data structures and types.

The value is constrained to the QUDT `unit` vocabulary
(for example, `http://qudt.org/vocab/unit/M` or
`http://qudt.org/vocab/unit/KiloW-HR`).
The QUDT ontology and specifications are available at <https://www.qudt.org/>.
