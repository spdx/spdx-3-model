# authorization  

## Summary

Authorization specifies the permissions, rights, privileges, or benefits granted to a Role, defining what the role is authorized to access, perform, or receive.

## Description

Authorization is a string property that captures the specific permissions, rights, privileges, or benefits that are associated with a Role. This property defines what the role is entitled to do or receive within a given context (e.g., build, system, distribution, supply chain, or lifecycle). For example, authorization might include access to certain resources, permissions to perform specific actions, or eligibility for particular benefits.
