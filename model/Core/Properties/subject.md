# subject

## Summary

The Element that an Annotation or Observation is about.

## Description

For an `Annotation`, the subject is the Element an annotator has made an
assertion about.

For an `Observation`, the subject is the Element observed
(the feature of interest).

## Metadata

- name: subject
- Nature: ObjectProperty
- Range: Element
