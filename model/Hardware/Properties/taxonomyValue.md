# taxonomyValue

## Summary

taxonomyValue is a value used to define an item within the taxonomy.

## Description

A taxonomy value is a specific term or label assigned within a taxonomy to define or identify an item, concept, or category. It represents a unique or standardized value within the classification system that helps categorize and describe the item's place or characteristics within the overall taxonomy.
