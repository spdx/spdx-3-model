# yAxisLength

## Summary

The length along the y-axis.

## Description

This property specifies the length along the y-axis of a hardware component. The value must be expressed using the /Core/UnitOfMeasure type which requires both a quantity, and a unitQUDT which must be a unit of length from the QUDT vocabulary, specifically constrained to the http://qudt.org/vocab/quantitykind/Length.

## Metadata

- name: yAxisLength
- Nature: ObjectProperty
- Range: /Core/UnitOfMeasure
