# xAxisLength

## Summary

The length along the x-axis.

## Description

This property specifies the length along the x-axis of a hardware component. The value must be expressed using the /Core/UnitOfMeasure type which requires both a quantity, and a unitQUDT which must be a unit of length from the QUDT vocabulary, specifically constrained to the http://qudt.org/vocab/quantitykind/Length.

## Metadata

- name: xAxisLength
- Nature: ObjectProperty
- Range: /Core/UnitOfMeasure
