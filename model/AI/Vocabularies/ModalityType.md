# ModalityType

## Summary

Specifies the modality of the inputs or outputs used by different Foundation Model (FM) based software components, like prompts and agents. 

## Description

List the different acceptable modalities of input or output used by the different FM-based components.

If the modality used by your component is not listed here, please select "other".

## Metadata

- name: ModalityType

## Entries

- 3D: Point clouds or 3D objects.
- audio: Speech or sound.
- geospatial: Maps or location data.
- image: Static visual content.
- multimodal: Combination of two or more modalities.
- Tabular: Row–column structured data.
- text: Written language.
- Time-series: Data over time.
- video: Moving visual content.
- other: Any other modalities not mentioned.
