# agentOutputModality

## Summary

Indicates the output modalities generated by the AI agent (e.g., text, structured data, images, audio).

## Description

Describes the forms of output produced by the agent when completing tasks or responding to inputs. This includes natural language text, structured data, visual outputs (e.g., images, plots, graphs), and audio outputs (e.g., synthesized speech, sound effects). Multimodal may be specified if the agent supports more than one modality.  

If no outputs are generated or the modality is unknown, set to NONE or NOASSERTION, respectively.
