# promptContent

## Summary

A link to a file with the prompt used with the Foundation Model. Provides a URI or file path to the stored prompt used for model execution or evaluation. 

## Description

Stores a reference (URI or file path) to the actual prompt provided to the FM during inference or evaluation. If the prompt is dynamically generated, please indicate no assertion.
