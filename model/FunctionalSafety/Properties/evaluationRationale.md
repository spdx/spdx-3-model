# evaluationRationale

## Summary

Detailed explanation or reasoning that supports the EvaluationResult.

## Description

Detailed explanation or reasoning that supports the EvaluationResult. It provides the underlying justification for why an evaluation was deemed to have passed, failed, or been inconclusive. This clarifies the decision-making process, citing evidence, criteria, analysis methods, and any considerations of uncertainties or risks.
