# requirementHierachyLevel

## Summary

Number indicating the hierachical level of the requirement whithin its namespace

## Description

The level of the requirement within the project that gave the requirement its namespace, using a positive number, e.g. in Zephyr: 1 for the Zephyr Safety Claims, 2 for Zephyr system requirements and 3 for Zephyr Software requirements 


## Metadata

- name: requirementNamespace
- Nature: RequirementProperty
- Range: PositiveIntegerRange
