# need

## Summary

A condition, objective or capability required by a role or element to solve a problem.

## Description

The statement property captures the natural language articulation of a Need. It represents the primary input for the Requirements Engineering process, preserving the original intent before transformation into verifiable system requirements.

While derived requirements must adhere to strict verification criteria, the need text within a Need may initially be qualitative or subjective. This property serves as the foundational traceability link, ensuring that downstream system capabilities can be traced back to the original intent. The need accommodates the unstructured nature of early elicitation, allowing for the recording of raw input prior to refinement.
