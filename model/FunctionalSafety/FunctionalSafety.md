# FunctionalSafety

## Summary

The FunctionalSafety profile is designed to provide a standardized way of documenting and
sharing information about artifacts created, verified and maintained during the safety lifecycle of a system.

## Description

The FunctionalSafety profile's namespace defines a set of concepts and data elements related to artifacts and their dependencies or links
to each other that are part of a safety related system's safety conformance documentation.

These artifacts include the outputs of engineering phases regarding planning, requirements analysis, system/software architecture, implementation, system analysis and verification tasks. The artifacts can be used to compile a standardized assurance case document.

## System impact analysis

The FunctionalSafety profile includes separate terms for assessing the impact
of analysis triggers and documenting the accomplishment of system changes.
SystemImpactAnalysis documents an assessment of one or more triggers and may
conclude that no change is required. SystemChangeAccomplishmentSummary
documents a system change and its supporting assurance evidence.

Usage guidance and worked examples for applying these terms are documented
separately from this profile overview.
