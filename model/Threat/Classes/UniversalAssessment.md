# UniversalAssessment

## Summary

Assessment using an aggregate of metrics from different systems.

## Description

Assessment using an aggregate of metrics from different systems including:

* BasicAssessment
* BsiAssessment
* ParkerianHexadAssessment
* MitreAssessment

In addition, metrics from other systems are contributed.
