# ProtectionCategory

## Summary

Controls may have different protection categories.

## Description

Describes the category of protection against a given threat.

## Metadata

- name: ProtectionCategory

## Entries

- preventative: Stop the threat from occurring (e.g., firewall, training).
- detective: Discover a threat that has already occurred (e.g., security audits).
- corrective: Fix the damage caused by a threat (e.g., restore from backup).
