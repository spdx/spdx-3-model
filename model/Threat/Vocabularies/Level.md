# Level

## Summary

Levels are metric values.

## Description

Metrics using Level as value type allow the evaluation according to predefined values. See Entries section for details.

## Metadata

- name: Level

## Entries

- U: undefined; the value is not known or yet undetermined
- I: ignore; the metric is to be ignored
- N: none; the metric was evaluated to be not relevant expressed by none
- L: low; the metric was evaluated to low
- M: medium; the metric was evaluated to medium
- H: high; the metric was evaluated to high
