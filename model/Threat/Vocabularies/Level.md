# Level

## Summary

Levels are metric values.

## Description

Metrics using Level as value type allow the evaluation according to predefined values. See Entries section for details.

## Metadata

- name: Level

## Entries

- undefined: the value is not known or not yet determined
- ignore: the metric is not evaluated; it does not apply or does not make sense in a given context
- none: the metric was evaluated to be not relevant
- low: the metric was evaluated to low
- medium: the metric was evaluated to medium
- high: the metric was evaluated to high
